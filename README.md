I recalculated expected answers from the question expressions, extracted each response's final integer (handling commas, brief prose, equations and Markdown), and scored numeric agreement across all three runs on those 50 questions. Corrected results: model-a 120/150 = 80.0%; model-b 125/150 = 83.3%. Per run, model-a scores 80%, 80%, 80%; model-b scores 88%, 84%, 78%. `python3 analyze.py` reproduces the original and corrected figures, audit findings, and uncertainty interval.

Model-b's point estimate is 3.3 percentage points higher, but this is weak evidence of superiority: a paired question-level bootstrap gives an approximate 95% interval for model-b minus model-a of −7.3 to +14.7 percentage points, including zero. Model-a is faster on this sample (median 0.88 s versus 1.42 s), so deployment depends on the accuracy/latency trade-off. These results do not prove which model is generally better; they cover only 50 distinct arithmetic prompts, these settings and three runs. Extracting the final integer is a dataset-specific assumption and may not work for arbitrary responses.
